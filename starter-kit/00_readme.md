# Starter Kit: PO Balloon Challenge

All data in this kit is synthetic. Ticket keys, names, and reviews are made up. Nothing here comes from real users.

**Treat "today" as Wednesday 2026-09-30 for every task that uses these files.**

## The sprint

- Sprint: MT Sprint 2026-S20
- Dates: Mon 2026-09-21 to Fri 2026-10-02 (10 working days)
- Snapshot: end of day Wed 2026-09-30. There are 2 working days left (Thu 2026-10-01 and Fri 2026-10-02).
- Project key: SBX (sandbox)

## Files

| File | What it is | Used in |
|---|---|---|
| `01_sprint-export.csv` | 20 sprint tickets: status, SP, assignee, priority, dates, blocked flag | A1, A3, B1-B3 (CSV fallback), C5, Boss |
| `02_one-star-reviews.csv` | 50 one-star Google Play reviews in Vietnamese | A4, B5, C3, C6 |
| `03_meeting-transcript.md` | Transcript of a 10-minute mid-sprint risk sync | A5 |
| `04_vague-ticket.md` | A ticket that is not ready for a sprint | A2, B4, C1 |
| `05_ai-sprint-summary.md` | A sprint summary written by AI. It contains mistakes. | A3 |
| `06_backlog-export.csv` | 12 backlog tickets not in the sprint | A6, B5 |

## Column notes

- `added_mid_sprint = Yes` means the ticket was not part of the commitment at sprint start.
- `blocked = Yes` means the ticket is flagged as blocked. `blocked_reason` says why.
- "Not updated in ≥ 3 days" means `updated` is on or before 2026-09-27.

## Safety

- Do not paste real user data (phone numbers, account IDs, transaction IDs) into any AI tool. This costs 1 balloon.
- Write tickets only to the SBX sandbox project. Writing to a real board costs 1 balloon.
